# ThunderPhone

AI phone agents that hear callers correctly, follow instructions, and run at 2–9¢ a minute.
Phone, web and app channels; 47 languages; SIP and carrier bring-your-own-number; testing and
grading built in.

Build on it from your coding agent:

- **Skills** for Claude Code, Codex, Cursor and any Agent Skills client: `npx skills add thunderphone/skills`
- **MCP server**: `https://api.thunderphone.com/v1/mcp` (agents, numbers, calls, tests, knowledge, campaigns, imports)
- **Docs for agents**: https://thunderphone.com/docs/llms.txt · any docs page as Markdown by appending `.md`
- **API**: https://thunderphone.com/docs · OpenAPI at https://thunderphone.com/docs/openapi.json
- **Examples**: [thunderphone/examples](https://github.com/thunderphone/examples)
- **Coming from Vapi, Retell, Bland or ElevenLabs?** https://thunderphone.com/import

Site: https://thunderphone.com · Developers: https://thunderphone.com/developers
